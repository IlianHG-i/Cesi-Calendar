Icônes nécessaires pour l'extension :
- icon16.png (16x16 pixels)
- icon48.png (48x48 pixels)
- icon128.png (128x128 pixels)

Vous pouvez utiliser le logo CESI ou créer une icône simple avec un calendrier.

Pour créer des icônes rapidement :
1. Utilisez un outil en ligne comme https://www.favicon-generator.org/
2. Ou utilisez GIMP/Photoshop pour redimensionner une image
3. Ou créez une icône simple avec du texte (par exemple "CESI CAL")

Pour le moment, l'extension fonctionnera sans icônes, mais Chrome affichera une icône par défaut.
