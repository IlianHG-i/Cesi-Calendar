CESI Calendar Exporter

Exportez votre emploi du temps vers Google Calendar

💡 Changez de jour avec les flèches ← → puis réexportez pour toute la semaine

📘 Comment utiliser l'extension ?

  1. Rechargez la page emploi du temps (F5)
  2. Vous verrez un badge ✓ CESI Exporter actif en bas à droite
  3. L'export démarre automatiquement après 2 secondes
  4. Ou cliquez sur le bouton ci-dessus pour exporter manuellement

💡 Vérifiez la console (F12) : des logs verts confirment que l'extension fonctionne

Importer le fichier dans votre calendrier

  1. Ouvrez votre application de calendrier
  2. Cherchez l'option Importer dans les paramètres
  3. Sélectionnez le fichier .ics téléchargé
  4. Choisissez le calendrier de destination et validez

💡 Astuce : créez un calendrier dédié "CESI" pour mieux organiser vos cours.
